# Сетевая игра «Морской Бой» 

Браузерная онлайн-игра «Морской бой» с высоким уровнем отказоустойчивости, защищенной авторизацией и современным технологическим стеком.

---

## 🚀 Технологический стек

Архитектура проекта разделена на три основных слоя (Frontend, Backend, Инфраструктура):

* **Frontend:** Vue 3 — отвечает за интерфейс, рендеринг игрового поля и формы ввода кодов.
* **Backend:** Go (Golang) — высокопроизводительный сервер, обеспечивающий бизнес-логику и мгновенный отклик.
* **База данных и Кэш:** * PostgreSQL — постоянное хранение учетных записей и ключей аутентификации.
  * Redis — оперативное хранилище (кэш) для изоляции и защиты состояния игровых комнат.
* **Протоколы связи:** WebSockets (WS) — для двустороннего обмена данными между клиентом и сервером в реальном времени.
* **Инфраструктура:** Kubernetes (k8s) — оркестрация, автоматическое масштабирование и управление контейнерами.
* **Хостинг:** Облачный провайдер Beget (Managed Kubernetes).

---

## 🏗️ Архитектура системы

Проект спроектирован с упором на производительность, безопасность и непрерывную доступность (High Availability).
